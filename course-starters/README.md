# Course-builder starters

These folders are templates for learner-owned workspaces. Do not edit them in place for an individual course.

- [Product Management for Consultants](product-management-consultants/README.md)
- [Technical Fluency](technical-fluency/README.md)

Use `scripts/new-course.ps1` on Windows or `scripts/new-course.sh` on macOS/Linux. Each script copies one starter outside this canonical repository, substitutes the workspace name, initializes a new Git repository, and verifies that no remote is configured.
