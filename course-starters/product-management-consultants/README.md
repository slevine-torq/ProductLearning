# Product Management for Consultants — course-builder starter

This folder is a **starter**, not a finished course. Copy it into a new folder with the repository bootstrap script before editing it.

## First session

1. Open the copied folder in a repository-aware AI assistant.
2. Ask it to read `AGENTS.md`, `AI-WORKFLOW.md`, `course-plan.md`, and `source-index.md`.
3. Pick one course line, module, and audience tier.
4. Record the intended outcome and source boundaries in `course-plan.md`.
5. Draft in `modules/`, place learner-facing deliverables in `outputs/`, and update `progress.md` and `decisions.md`.

Do not paste captured source material into new output wholesale. Rebuild it for the Torq consultant audience, preserve attribution, and keep the original module structure when the source build method requires it.
