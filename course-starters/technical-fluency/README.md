# Technical Fluency — course-builder starter

This folder is a safe workspace for extending or adapting Technical Fluency for Transform Practice. Copy it with the repository bootstrap script before editing it.

## First session

1. Open the copied folder in a repository-aware AI assistant.
2. Ask it to read `AGENTS.md`, `AI-WORKFLOW.md`, `course-plan.md`, and `source-index.md`.
3. Use the program specification and reference guide to select the next task. Courses 0–2 are already built; Course 3 is the default starting point for new work.
4. Map the required terms and three tier reads in `course-plan.md`.
5. Draft in `modules/`, place learner-facing deliverables in `outputs/`, and update the progress and decision logs.
