# Product-work workspace starter

This is a Torq-authored, tool-neutral workspace for product work on an approved engagement. Copy it with the ProductLearning bootstrap script before using it.

## First session

1. Open the copied folder in Claude Code, Codex, Kiro, Cursor, or another approved repository-aware assistant.
2. Ask it to read `AGENTS.md`, `WORKSPACE.md`, and `AI-WORKFLOW.md`.
3. Fill in `product-context.md`, `strategy.md`, `stakeholders.md`, and `evidence-index.md` using only approved information.
4. Put rough work in `working-notes/`, source-backed research in `research/`, reviewable outputs in `deliverables/`, and repeated routines in `workflows/`.
5. Record meaningful choices in `decisions.md` and material workspace changes in `change-log.md`.

Never place secrets, credentials, regulated data, or unapproved client information in this repository. The Git history may persist even after a file is deleted.
