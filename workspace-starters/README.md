# Product-work workspace starters

These templates are for everyday product work on an approved client engagement. They are separate from the [course-builder starters](../course-starters/README.md), which are only for creating or extending learning content.

Create a product-work workspace with the PowerShell or Bash bootstrap script described in [Workspace quickstart](../WORKSPACE-QUICKSTART.md). The script copies the template to a new destination, creates an independent Git repository, refuses to overwrite an existing folder, and configures no remote.

Do not edit the template in place. Do not copy the ProductLearning source library into a client workspace.
