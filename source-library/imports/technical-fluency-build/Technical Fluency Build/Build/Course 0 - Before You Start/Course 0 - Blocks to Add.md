## Task: What tier am I? — additional Blocks

Add these to the same Task as the lesson's HTML upload, via "+ Add block."
They share that Task's one Mark Complete — no new Task title needed for any of them.

### Block: Tier Key Terms — Type: Card flipping
**Cards (term → definition):**
1. Term: Scope | Definition: How large and how ambiguous the territory you're responsible for. Granted to you, rather than demonstrated.
2. Term: Autonomy | Definition: How little help you need to succeed inside your scope — whether you need a template, a reviewer, or a decision supplied.
3. Term: Impact | Definition: What actually shipped and what it did. At Tier 2 the test is whether a client changed a decision because of the work.
4. Term: Tier 2 | Definition: Consultant / Sr. Consultant. Owns a workstream end to end, including its ambiguity, and defends the output in the room.
5. Term: Tier 3 | Definition: Principal / AD / Director. Shapes the engagement and carries the commercial terms — the same technical facts as Tier 2, attached to money, time, and risk.
6. Term: A different axis, not a higher one | Definition: The rule that Tier 3 is not deeper engineering knowledge than Tier 2. It is the same L3 facts with the commercial consequence attached.

### Block: Which dial? — Type: Quiz
1. A consultant is handed a fully scoped workstream, delivers it on time with a reviewer's sign-off, and no client decision changes as a result. Which dial is lagging?
   A. Scope
   B. Autonomy
   C. Impact  ← correct
   D. None — this is a Tier 2 profile

2. A client says "we're on a Java monolith with no CI/CD." Which question is the Tier 3 read?
   A. "What does that do to your release cadence, and what would it take to change?"
   B. "What does that do to the estimate, the hiring plan, and what phase two can promise?"  ← correct
   C. "How many services would you split it into?"
   D. "Which JVM version are you running?"

3. According to the promotion mechanism in this task, how do you reach the next tier?
   A. By collecting the skills listed on a rubric
   B. By waiting until a larger scope is assigned, then performing in it
   C. By demonstrating autonomy and impact at your current scope  ← correct
   D. By spending a set number of years at the current tier

4. Which statement about the three dials is true?
   A. They move together, so one number describes a consultant
   B. They frequently disagree, and the disagreement is the useful signal  ← correct
   C. Scope is demonstrated; autonomy and impact are granted
   D. Impact is the only one a Torq lead can observe

## Task: What moving up takes — additional Blocks

Add these to the same Task as the lesson's HTML upload, via "+ Add block."
They share that Task's one Mark Complete — no new Task title needed for any of them.

### Block: Moving Up Key Terms — Type: Card flipping
**Cards (term → definition):**
1. Term: Tier 2 is a destination | Definition: Most Torq client work happens at Tier 2, and staying there as a high-performing independent consultant is a legitimate choice — not a stall.
2. Term: A job change, not a skill upgrade | Definition: The step from Tier 1 to Tier 2. More execution craft doesn't get you there; owning ambiguity and defending a position does.
3. Term: The five currencies | Definition: Product, execution, strategic, leadership, and people-management skills — each earned separately, rather than combining into one seniority score.
4. Term: Influence without authority | Definition: The defining Tier 2 capability, and the one most consulting engagements test hardest.
5. Term: The rubric guardrail | Definition: Ladders specific enough to score end up circular — rating someone senior for having been given senior work. Behaviors someone can watch are the alternative.
6. Term: Observable behavior | Definition: A tier difference stated as something a Torq lead can watch happen on an engagement, rather than an adjective to be inferred from a self-description.

### Block: Earlier tier or later tier? — Type: Card classification
**Buckets:** Earlier tier, Later tier
**Cards to sort (statement → correct bucket):**
1. "Wants the question answered before starting" → EARLIER TIER
2. "Works without templates, and supplies them for others" → LATER TIER
3. "Escalates the trade-off" → EARLIER TIER
4. "Argues for what should be worked on" → LATER TIER
5. "Optimizes their own deliverable" → EARLIER TIER
6. "Thinks in terms of the next several deliverables" → LATER TIER
7. "Is coached" → EARLIER TIER
8. "Comfortable starting with the question unsettled" → LATER TIER
