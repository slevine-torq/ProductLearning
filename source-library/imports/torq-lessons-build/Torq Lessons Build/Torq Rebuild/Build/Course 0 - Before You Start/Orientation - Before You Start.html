Before you start

Six courses, one folder on your own computer. Read this once — it's the only task with nothing to download.

Read time ~4 min Artifact None — setup only

This certification is built to be used on the job, not binged in one sitting. Here's how it's organized, how fast to move through it, and the one thing to set up before Task 1.

Six courses, taken in order — each unlocks when the one before it is complete. Every task is short and ends in something you build for your own current engagement: a canvas, a worksheet, a template. Not a quiz to pass and forget.

How to pace it

Most new material fades within a day or two without reinforcement — that's true whether you're in a classroom or reading a task on your laptop. Spreading this out beats binging it.

  • Aim for ~20–30 minutes a day, not a task count. Tasks vary in length — total time is the real budget, not "exactly 2 tasks."
  • Two short tasks a day is a reasonable default given how tight these are, but one longer task some days is completely fine.
  • At that pace, the whole certification is about a week. Slower is fine. This isn't a race, and every task stays available as a reference afterward.

Set up your workspace

By the time you finish this program you'll have built 35 real artifacts — roadmaps, PRDs, briefs, checklists — each one modeled on something you'd actually hand a client. Left as browser downloads, they scatter and get lost. Five minutes now gives them one real home instead, with version history, sitting on your own machine, ready to reuse on your next engagement.

It downloads as plain Markdown. No GitHub account, no sign-up, no internet connection required.

Terminal 
# run these once, before Task 1
mkdir -p "Torq Product Practice"/01-strategic-thinking
mkdir -p "Torq Product Practice"/02-discovery
mkdir -p "Torq Product Practice"/03-analytics
mkdir -p "Torq Product Practice"/04-roadmaps
mkdir -p "Torq Product Practice"/05-experimentation
mkdir -p "Torq Product Practice"/06-launch
cd "Torq Product Practice"
git init

That's the entire setup — copy the block above into a terminal, once, before Task 1. No account of any kind.

After each task

  1. Click Download as .md on the task's artifact — it's named to match its folder.
  2. Move it into the matching numbered folder.
  3. Commit it: git add . && git commit -m "..."

Optional, never required: if you already have a GitHub account and want an off-machine backup, you can add it as a remote later and push. That's a bonus on top of this, not part of the setup.
