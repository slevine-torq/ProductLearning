# pm-workspace

Your working project folder for **Claude Code for PMs**.

> **Note:** Product School's official `pm-workspace` template (linked from the course's Pre-Class Setup and every module's Resources section) currently 404s and doesn't yet exist on their GitHub org — confirmed by checking both your account and `github.com/product-school`. This repo is a stand-in scaffold, built from the folder structure and file conventions described across Modules 1–4, so you're not blocked on the course's fork-a-template step. Swap in the real template if/when Product School publishes it.

## Structure

- **`CLAUDE.md`** — loaded automatically at the start of every Claude Code session. Built in **Lesson 1.3**.
- **`project.md`**, **`strategy.md`**, **`change_log.md`** — your three core files (source of truth, current direction, decision trail). Built in **Lesson 1.4**.
- **`skills/`** — reusable `SKILL.md` prompt packages. First one (weekly status update) built in **Lesson 1.5**.
- **`01-orient/`** — Module 1 output: CLAUDE.md, three core files, first skill.
- **`02-research/`** — Module 2 output: interview insight synthesis, feedback report, competitive matrix, decision brief.
- **`03-build/`** — Module 3 output: working prototype, iteration log, hypothesis statement, triad session plan.
- **`04-team/`** — Module 4 output: codebase tour, spec-readiness checklist, design review, edge-case/QA checklist.

Each folder currently has a placeholder — replace it with your actual lab artifact as you complete each module.

## Getting started

Open this folder in Claude Code and run your first prompt:

```
What can you do in this session? What files can you see?
```

Then move into Module 1, Lesson 1.2 (The AI Interview) before building anything.
