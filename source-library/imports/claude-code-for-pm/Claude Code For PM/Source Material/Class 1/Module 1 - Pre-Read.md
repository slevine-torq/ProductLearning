**Claude Code for PMs · Module 1 · Pre-Read**

> 15 min. Skim before the live session. Module 1 covers **Get Oriented**. This course is built on Anthropic's Claude Code; you do not need to write code, but you should have Claude Code installed and a project folder ready before class.

## What you'll do in this module

By the end of the 2-hour session plus the self-paced labs (~160 min), you will have committed these artifacts to `01-orient/` in your `pm-workspace/` repo fork:

- **1.1 How Claude Code Actually Works** → Your first Claude Code-generated PRD skeleton, built from a messy Slack thread in under two minutes.
- **1.2 The AI Interview, Getting to What You Actually Need** → A Claude-generated plan summary you approved before a single file was written, and the habit of running this before every project.
- **1.3 Persistent Memory Across Sessions** → A CLAUDE.md file that primes every future session, the spine of your workspace.
- **1.4 Your Three Core Files** → A three-file project architecture you use in every session from here on.
- **1.5 Building Skills You Reuse** → A reusable Weekly Status Update skill, your first piece of compounding infrastructure.

## The throughline scenario

You are a PM on the **Engagement squad** at **Streakly**, a consumer habit + micro-learning app. Day-7 retention slipped from **48% to 39%** after a v2 redesign — users start a streak, break it in week 1, then never come back. The tension: more re-engagement nudges vs. notification fatigue. Across the six modules you build toward the **Comeback experience**, and the **Comeback Coach**, an agent stack that diagnoses churn and learns, that wins those users back. Every lab commits a real artifact to your repo.

---

## The mindset shift

> **Stop chatting with AI. Start configuring it.**

A working PM doesn't sit in a chat window rephrasing prompts. They set up persistent context once, build reusable skills, and, by Module 6, let agents run the repetitive work on a schedule. Module 1 is one stage of that system.
