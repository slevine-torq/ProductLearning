## Locked decisions to preserve

- Seven courses, 39 Tasks, no tenure gatekeeping.
- All three tier reads appear in every Task and share the same underlying technical fact.
- Tier 3 adds commercial/risk interpretation rather than deeper technical implementation.
- No artifact canvas and no JavaScript in Tasks; each Task ends at key takeaways.
- Each Task produces self-contained HTML plus its section in the course's TorqHub block sheet.
- Use real, verifiable public examples; do not invent a running fictional company.
- Build Course 6 last because it synthesizes the prior courses in the client room.
