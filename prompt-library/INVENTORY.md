## Exclusions and normalization

- Slide speaker questions are cataloged as reflections only when they ask the learner to produce or examine an answer; ordinary rhetorical slide copy is not treated as a prompt.
- Buttons such as “Copy prompt + my data” are UI controls, not separate prompts.
- Scenario data embedded by a builder is an input occurrence, not a new prompt.
- Identical or materially identical prompt wording is listed once with multiple occurrences.
- No prompt text in `source-library/imports/` was edited during this review.
